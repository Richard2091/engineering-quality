# 实施前向测试场景

请使用 `$engineering-quality` 处理一个包含前端页面、后端接口、数据库迁移和容器部署的模型监控示例项目，新增“按模型查看监控指标”的功能。要求在实施阶段遵循工程化规范，最后输出变更总结、测试结果、复审结论和待确认事项。

## 观察点

- 是否先读取仓库规则并建立项目画像。
- 是否明确目标、非目标、输入输出和验收标准。
- 是否按项目类型加载前端、后端、数据/模型和交付规则。
- 是否先给出模块、文件、接口、测试、安全、观测和回滚计划。
- 是否按需要拆分阶段，并为每阶段提供完成标准和独立复审。
- 是否处理加载/空态/错误态、接口校验、超时、权限、数据兼容和迁移。
- 是否关注大文件、目录过多和重复职责，而不是机械新增文件。
- 是否根据风险决定工作树、分支、合并请求和部署目标，而不是擅自猜测。
