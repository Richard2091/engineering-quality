# 数据、数据库和模型工程化规则

按项目是否处理持久化数据、数据管道、机器学习或模型推理选择相关条目。

## 数据生命周期与质量

检查数据来源、所有者、字段语义、时间和时区、空值、唯一性、版本、保留期、清理、脱敏、访问审计、加密、备份和删除。区分业务数据、日志、缓存、临时文件和模型产物；为关键数据定义质量规则和异常处理。

## 数据处理与数据库

检查模式和迁移、约束、事务、索引、查询容量、并发、锁、连接关闭、备份恢复和数据损坏处理。数据处理要覆盖重复、乱序、部分失败、重跑、断点、幂等、血缘、质量指标、超时、重试和告警。

## 模型与推理

检查模型和数据版本、训练/推理环境一致性、输入输出契约、评估指标、阈值、推理超时、资源和调用成本、模型回滚、结果解释、漂移、偏差、敏感数据和人工兜底。没有模型生产场景时标记不适用。
