# 数据与模型项目类型规则

## 适用条件

当项目包含数据采集、数据处理、数据库模式、数据管道、特征、模型训练、模型评估、模型推理或模型监控时启用。只有普通业务对象且没有数据处理/模型生命周期时，不必启用全部条目，可按实际范围选择。

## 项目类型画像

实施或审查前记录：

- 入口：采集任务、批处理、流处理、训练、评估、推理、监控和回填入口。
- 核心资产：数据契约、数据字典、模式、迁移、任务、特征、模型、评估报告和产物。
- 主要依赖：数据源、数据库、对象存储、队列、编排器、模型运行时和外部服务。
- 关键风险：数据污染、重复处理、版本错配、隐私泄露、模型回归、漂移、成本失控和无法恢复。
- 生命周期：探索、开发、离线验证、预发布、生产、回填、重训或模型退役。

## 需求与设计

### 数据和模型边界

- 明确数据所有者、使用目的、字段语义、质量目标、保留期、删除要求和访问角色。
- 明确数据输入输出、时间时区、空值、唯一性、乱序、重复和迟到数据口径。
- 区分原始数据、清洗数据、特征、标签、日志、缓存、临时文件和模型产物。
- 明确模型、数据、特征、配置、代码、运行时和评估结果的版本关联。
- 明确推理阈值、人工兜底、降级、漂移响应和模型回滚条件。

### 数据流与失败策略

设计采集、校验、转换、存储、消费、产出和清理的数据流；明确部分失败、重跑、断点、补偿、回填、重复、乱序和上游不可用时的行为。

## 实施规范

### 阶段化流程

1. 确认数据/模型目标、口径、非目标和验收指标。
2. 调研来源、所有者、契约、模式、任务、版本和现有质量规则。
3. 设计数据流、存储、任务状态、版本、权限、成本和恢复方案。
4. 分阶段实现数据处理、模式/迁移、模型或推理变化。
5. 执行数据质量、模型回归、性能和恢复验证。
6. 输出数据字典、迁移/回滚、评估、发布和运行说明。

简单查询或指标展示可以直接实施；涉及模式、数据回填、训练、推理、敏感数据或生产任务时必须分阶段，每阶段具备方案、实现、测试、审查、风险和完成标准。

### 数据处理与数据库

- 输入校验覆盖类型、范围、时间、空值、唯一性、编码和敏感字段。
- 任务支持幂等键、断点、重跑、批次标识、处理水位、失败重试和最终失败告警。
- 迁移脚本支持多环境、幂等执行、旧版本兼容和失败补偿；评估固定 ID、索引、锁和大表分批。
- 数据质量规则至少覆盖完整性、唯一性、及时性、分布异常和引用一致性中适用部分。
- 记录数据血缘、输入批次、代码版本、配置版本和产出位置，便于复现。
- 敏感数据最小化采集、脱敏/加密、访问审计、保留清理和删除验证。

### 模型与推理

- 训练数据、代码、依赖、参数、模型文件和运行环境可追踪。
- 评估集、指标、阈值、基线、分群表现和已知限制明确；不能只保留单一平均指标。
- 推理接口定义输入输出、版本、超时、资源上限、批量上限、错误和降级。
- 发布前进行离线回归、必要的线上影子/灰度验证和成本评估；真实环境须单独授权。
- 监控延迟、错误率、资源、调用量、成本、数据质量、漂移和结果分布；明确告警和处置人。
- 模型回滚必须同时考虑代码、配置、模型文件、特征和数据兼容。

## 测试规范

- 数据契约测试：字段、类型、必填、枚举、时间时区和版本兼容。
- 数据质量测试：完整性、唯一性、范围、分布、及时性、重复、乱序和异常值。
- 处理任务测试：幂等、重跑、断点、部分失败、补偿、并发和最终状态。
- 数据库测试：迁移、约束、索引、回滚/前向修复、备份和恢复。
- 模型测试：输入边界、输出契约、离线指标、回归、分群、偏差、漂移和资源成本。
- 推理测试：超时、限流、降级、模型版本、错误脱敏和客户端兼容。

测试失败必须定位并修复后重新验证。测试记录包含命令、环境、输入数据/批次、输出、数据状态、指标、最终结论和未验证原因。生产数据、真实推理流量和真实回填操作必须单独授权。

## 交付与运维

交付物按变更判断是否包含：数据字典、数据契约、模式/迁移脚本、回滚或补偿方案、质量报告、模型评估报告、模型卡/限制说明、推理接口文档、监控告警、运行手册和变更记录。

发布前确认版本追踪、配置、资源配额、超时、告警、备份、恢复目标和观察窗口。发布后检查任务最终状态、数据质量、接口延迟、错误率、成本和模型指标。没有恢复演练证据时标记未验证。

## 典型问题和反模式

- 数据字段没有所有者、语义、版本和删除策略。
- 任务失败后重复写入或只能从头重跑。
- 迁移脚本不可重复执行，回填没有限速、批次和补偿。
- 训练、模型、数据和推理代码版本无法关联。
- 只看平均模型指标，不看分群、偏差、漂移和线上回归。
- 推理没有超时、资源上限、降级和成本监控。
- 将敏感原始数据复制到日志、样例或调试文件。
- 有备份但没有恢复验证，回滚只切换代码不处理数据/特征兼容。

## 验收证据

检查数据契约、数据字典、模式/迁移、任务编排、样例、质量规则、血缘、模型注册/版本、评估报告、推理接口、监控告警和恢复记录。

保留输入来源和批次、代码/配置/模型版本、执行命令、指标和输出、数据状态、发布与回滚记录、恢复验证以及剩余风险。
