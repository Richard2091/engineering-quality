# 基础设施和平台工程化规则

仅当项目包含基础设施即代码、编排、云资源、网络、权限或平台自动化时启用。

## 变更安全

检查资源命名、环境隔离、状态文件、锁、漂移检测、计划预览、审批、最小权限、密钥引用、敏感输出和破坏性变更保护。资源删除、数据迁移和权限扩大必须有明确影响分析与回滚/恢复方案。

## 可复现与可审计

检查模块边界、变量和默认值、版本锁定、提供商来源、状态备份、制品追踪、审计日志、策略检查和持续集成门禁。避免把环境差异隐藏在脚本分支中。

## 验证

优先执行格式、静态策略、计划检查、隔离环境验证和恢复演练；禁止未经授权直接触碰生产资源。无法连接目标环境时，应输出未验证项而非推断通过。
