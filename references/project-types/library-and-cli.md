# 软件库和命令行工程化规则

仅当项目产出可复用库、命令行工具或软件开发工具包时启用。

## 公共契约

检查公共类型、接口、错误模型、参数校验、线程安全、资源生命周期、兼容矩阵、弃用策略和语义化版本。公共接口必须有文档和最小可运行示例，行为变更必须记录在变更日志中。

## 产物与使用体验

检查包元数据、锁定与构建、源码映射、许可证、平台支持、命令退出码、标准输入输出、日志与机器可读模式。命令行工具应明确帮助、配置优先级、超时、信号、临时文件和失败后的清理。

## 验证

至少验证公共接口、错误分支、版本兼容、安装/卸载、重复执行和发布产物；不因库没有服务端而跳过安全、依赖和供应链检查。
