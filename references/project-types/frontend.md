# 前端工程化规则

仅当项目包含浏览器、桌面网页或前端资源时启用。

## 结构与状态

检查页面、组件、状态、路由、请求层、业务逻辑和样式的边界；识别过大组件、重复结构、全局变量污染、内联副作用和请求逻辑散落。区分服务端状态、页面状态、表单状态和展示状态，避免不必要的全局状态。

## 交互与安全

检查加载、空态、错误态、无权限态、重试、取消、重复提交和离线行为。动态内容按上下文转义，富文本使用可信白名单；检查开放重定向、跨站请求、令牌存储、敏感信息展示和第三方脚本边界。

## 性能、可访问性与兼容

检查包体积、代码分割、缓存、长列表、图片字体、重复请求、渲染抖动和错误采集。按适用性检查语义化结构、键盘操作、焦点、对比度、替代文本、表单提示、错误可读性和浏览器兼容矩阵。

## 交付证据

检查格式化、类型检查、构建、组件测试、接口模拟、浏览器测试、性能报告、前端异常采集和部署产物。实施新页面或组件时，文件拆分以页面职责、复用边界和变化原因判断，不为拆分而拆分。
