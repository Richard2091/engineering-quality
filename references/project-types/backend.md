# 后端和接口工程化规则

仅当项目包含网络服务、接口、常驻进程或后台任务时启用。

## 服务生命周期

检查启动配置校验、启动失败、健康/就绪检查、优雅关闭、后台线程异常、信号处理和任务恢复。守护线程不能成为静默失败的借口。

## 请求与外部调用

检查输入校验、请求体大小、认证授权、请求和上游超时、重试次数与退避、限流、并发上限、单飞、幂等、背压、资源耗尽、错误脱敏和审计。管理、诊断和高成本接口需单独检查暴露范围。

## 数据库与事务

检查连接生命周期、事务边界、提交回滚、并发写、锁超时、连接池、索引、查询范围、分页、迁移可重复执行、清理、备份和恢复。使用文件或轻量存储时按实际并发模型评估，不机械要求某种数据库。

## 接口契约

检查路径、方法、参数、响应、错误码、版本、兼容、分页、排序、过滤、幂等和废弃策略。接口测试应验证成功、鉴权失败、参数错误、资源不存在、上游失败、超时和客户端断开等分支。
